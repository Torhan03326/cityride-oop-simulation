# CityRide OOP Simulation

Object-oriented micro-mobility simulation demonstrating extensible system design and design patterns in Python.

## Overview

This project is a proof-of-concept simulation for a fictional micro-mobility company called CityRide. The system models riders, vehicles, pricing plans, zones, billing, logging, and city-specific configurations.

The main goal was to demonstrate how object-oriented programming and design patterns can make a system easier to extend, maintain, and adapt to future changes.

## Key Concepts

- Object-Oriented Programming
- Abstraction
- Encapsulation
- Polymorphism
- Open/Closed Principle
- Separation of Responsibilities
- Loose Coupling

## Design Patterns Used

- Strategy Pattern
- Decorator Pattern
- Observer Pattern
- Abstract Factory Pattern

## Features

- Scooter and bike vehicle types
- Dynamic pricing plans
- Runtime pricing strategy switching
- Add-ons such as helmet rental and insurance
- Loyalty point discounts
- Zone fees and no-ride zones
- Fleet management and vehicle availability tracking
- Event-driven billing and ride logging
- City-specific configuration through Abstract Factory

## Academic Context

This project was developed as part of the UC2OOP101 Object-Oriented Programming course and received a final grade of A.
